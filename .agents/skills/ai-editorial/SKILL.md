# AI Editorial Workflow

Use recent verifiable AI news when available. If no suitable news passes review, consider an AI or automation GitHub project; verify its repository, licensing, star-count observation time and practical limitations. A historical project is not a newly launched product. Explain the reader's task, evidence, a practical action and limits; do not fabricate tests, popularity or engagement.

Record sources, checks and a single editorial experiment. Make an image storyboard tied to the article and sources; generate or source images only with an appropriate use basis. Inspect the actual images and mobile layout; automated pixel checks do not replace visual review.

Use the scripts and approval workflow in README.md. Save only a WeChat draft after the gates pass. Reopen the same draft and verify its contents before claiming delivery. On unknown outcomes, check for an existing draft and do not recreate it. Never publish publicly, access other destinations, or persist credentials unless separately authorized.
